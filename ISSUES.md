## 💡 Price Calculation Reference (Customer Portal)

What the customer sees in `BookingDetailDrawer.jsx`:

```
Booking Amount  = booking.price.total  (what they paid)
Refund Processed = booking.cancellation.refundAmount  (negative, shown in purple)
NET TOTAL       = booking.price.total - refundAmount  (= 0 for full refunds)
```

The customer portal never shows Platform Fee or Provider Earnings — those are internal.

> [!CAUTION]
> The `paymentStatus` comparison MUST be case-insensitive. The backend returns lowercase (`"refunded"`, `"paid"`, `"partially_refunded"`), but older check strings in the UI use title-case (`"Refunded"`, `"Paid"`). This causes silent display failures for refunded bookings.
